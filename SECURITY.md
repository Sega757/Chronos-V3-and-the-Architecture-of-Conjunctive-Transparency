# Security Policy

## Supported Versions

Currently, as this is a newly initialized repository, we support security updates for the following versions:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do NOT open a public GitHub issue. Instead, please report it via one of the following methods:

1. **Email:** [security@yourdomain.local](mailto:security@yourdomain.local) (Placeholder - please update when the project is hosted)
2. **GitHub Security Advisories:** Submit a private vulnerability report via the "Security" tab on GitHub once available.

### What to Include in Your Report

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce (or a proof of concept script/exploit).
- Potential impact (e.g., privilege escalation, information disclosure).
- Any proposed fixes or remediations.

### Our Response Process

1. **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
2. **Investigation:** We will investigate and reproduce the issue, keeping you informed of our progress.
3. **Remediation:** If verified, we will work on a fix and release a security advisory and patched version as soon as possible.
