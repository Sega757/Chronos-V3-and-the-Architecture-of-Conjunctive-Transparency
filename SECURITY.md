# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report
- Please report security vulnerabilities privately using GitHub's Private Vulnerability Reporting feature on this repository, or contact the repository maintainers.
- Include a detailed description of the issue, steps to reproduce, and potential impact.

### Response Time
We aim to acknowledge receipt of vulnerability reports within 48 hours and provide updates as fixes are developed.
